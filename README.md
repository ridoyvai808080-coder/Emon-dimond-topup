# Emon Top Up

Modern game top-up storefront for GitHub Pages.

## Included
- Login/register demo
- Modern responsive UI
- Free Fire, FF UniPin, 200 Like, Evo Access, Level Up Pass and PUBG UC
- Package selection and Player ID
- bKash/Nagad payment numbers
- Transaction ID field
- Buy Now opens WhatsApp with a pre-filled order message

## WhatsApp
The site uses WhatsApp click-to-chat. The customer still needs to press **Send**; a normal static GitHub Pages site cannot silently send WhatsApp messages.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages from the repository's Pages settings.
